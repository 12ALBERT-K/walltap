## 5. WHAT WAS FIXED TODAY (all committed + live)

The big one: the app looked deployed but every API call 503'd.

  * DATABASE_URL used Supabase's DIRECT host (db.<ref>.supabase.co), which is
    IPv6-ONLY (AAAA record, no A record). Render free tier has no IPv6 egress →
    ENETUNREACH → initSchema() failed → ready=false → every route 503'd while
    / and /config.js still returned 200, so it LOOKED deployed.
    Fix: use the IPv4 pooler. → commit 27120be
  * sslmode=require breaks node-postgres against Supabase (self-signed cert).
    Only sslmode=no-verify works. → .env
      Verified by direct test against db.hbcsujvcizcnpgxkcxuu.supabase.co:5432
      using the repo's own `pg`:
        sslmode=require  -> FAIL: self-signed certificate in certificate chain
        sslmode=prefer   -> FAIL: same
        sslmode=verify-ca-> FAIL: same
        sslmode=no-verify-> OK
      Do not "correct" this back to `require` — it is what the pg driver treats
      as an alias for verify-full. server.js:256 only passes its own
      `ssl:{rejectUnauthorized:false}` when the URL has NO sslmode= at all, so
      whatever you put here is what pg uses. no-verify and omitting sslmode are
      equivalent; no-verify is the explicit, self-documenting choice.
  * public/app.js declared top-level `const supabase`; the Supabase CDN bundle
    declares `var supabase` globally. Two classic <script> tags → SyntaxError at
    PARSE time → entire file dead, zero listeners, login button inert.
    Fix: wrapped app.js in an IIFE (2 lines, no rename).
    → commit 37b69d8
  * provision-admin left a half-created confirmed account when its grant failed,
    dead-ending the retry. Now reuses the trigger's username + rolls back.
    → commit acbd7a5
  * server.js now binds the port BEFORE DB init, so slow init can't fail a
    deploy health check. → commit aed5e86
  * preflight.js now FAILS on an IPv6-only DATABASE_URL host, so the 503-only
    deployment can't silently come back.

Commits (main repo, master): 37b69d8 · 0a91414 · acbd7a5 · a06801e · 27120be ·
26b3a47 · aed5e86. Admin repo still at 6af955e.
